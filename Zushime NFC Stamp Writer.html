ZUSHIME NFC STAMP WRITER

Staff tool. Writes the stamp link onto an NFC sticker so a tap opens the loyalty card and adds today's stamp.

The link must end in #stamp. If you later move the card to your own domain, change it here and rewrite the stickers.

Open this file in Chrome on an Android phone with NFC on.

  1. Open this file in Chrome for Android (NFC turned on). It must be served over https, or use the NFC Tools fallback below.
  2. Tap Write sticker, then hold the phone against a blank NFC sticker until it confirms.
  3. Tap Verify and test with a customer phone: iPhone opens the link on tap, Android opens it too.
  4. Stick it on the table or counter, clear of metal (use on-metal stickers if needed).
  1. Install NFC Tools (free).
  2. Write > Add a record > URL / URI.
  3. Paste the stamp link above, tap OK, then Write and hold near the sticker.

Sticker spec: NTAG213 / 215 / 216, NDEF formatted, ISO 14443A. The record is one NDEF URL record, about 60 bytes.
